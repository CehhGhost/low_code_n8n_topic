# n8n Workflow Lab

**Тема:** Low-code автоматизация бизнес-процессов и интеграция информационных систем на примере n8n.

Студенты создают workflow обработки обращений пользователей: принимают JSON через Webhook, проверяют входные данные, получают пользователя из Mock API, назначают ответственную группу и SLA, регистрируют обращение и корректно обрабатывают ошибки. Дополнительные задачи: Retry при временных сбоях и защита от повторной регистрации. Оценивание: **Б / Б+ / П** по качеству базового решения; **Э** за полностью выполненную базу и обе дополнительные задачи.

> **Статус репозитория: этап 2 (учебная инфраструктура).** Docker Compose и обучающий workflow подготовлены; полноценный Mock API, рабочий шаблон основного ДЗ и автоматические функциональные тесты еще не созданы. Запуск n8n в Docker на целевой версии еще не проверен в реальной среде. **Пока не выдавать студентам как готовое ДЗ.**

## Быстрый старт этапа 2

Установите Docker Desktop / Docker Engine с Compose v2, затем из корня репозитория:

```bash
docker compose up -d
```

- Откройте [http://localhost:5678](http://localhost:5678) и создайте локального owner при первом запуске.
- Проверьте Mock API: [http://127.0.0.1:8080/users/451](http://127.0.0.1:8080/users/451).
- В интерфейсе n8n импортируйте [`workflows/tutorial-basics.json`](workflows/tutorial-basics.json) через меню **Import from File**.
- Запустите пример и прочитайте пояснения Sticky Notes на схеме.

Подробности: **[инструкция по запуску](docs/SETUP.md)** и **[мини-практикум](docs/N8N_BASICS.md)**.

## Что работает в текущем прототипе

- n8n в изолированном контейнере, с сохранением данных в Docker volume;
- демонстрационный Mock API: `/health`, `GET /users/{id}` (три тестовых пользователя);
- учебный workflow: Manual Trigger, Edit Fields, If, HTTP Request, Switch, Sticky Notes;
- проверка вспомогательного Python API и структуры проекта без сторонних Python-библиотек.

**На следующем этапе** Mock API будет расширен до `POST /requests`, `GET /requests/{requestId}`, служебных endpoints для настройки сбоев и инспекции запросов, а затем появятся полноценные функциональные тесты.

## Технические и юридические оговорки

- Локальная Community Edition n8n не требует платных ключей для этого учебного сценария.
- Порты на хосте привязаны к `127.0.0.1`. Это не конфигурация для публичного хостинга.
- Используется закрепленная версия n8n `2.43.7`, а не `latest`.
- Docker недоступен в среде разработки этого архива, поэтому реальный старт контейнеров и импорт workflow требуют проверки на машине с Docker.
