# n8n Workflow Lab - итог проектного этапа

**Статус:** проектирование завершено. На этапе 2 были созданы Docker Compose и обучающий workflow. На этапе 3 реализован Mock API и его контрактные тесты. Впереди - основной workflow и автотесты студенческого решения.

## Суть задания

Студент получает готовое окружение и пример учебного workflow для знакомства с n8n. Затем создает самостоятельный workflow автоматизации обработки обращений с Webhook, валидацией, запросом пользователя, маршрутизацией, определением SLA, регистрацией и обработкой ошибок.

## Решения

- Сервис: локальный Mock API с пользователями и регистрацией обращений.
- API студента: `POST /webhook/support-request`.
- Ответы: 201 при успехе, 400 при неверных данных, 404 при отсутствии пользователя, 502 при сбое внешнего API.
- Проверка: HTTP-ответы, записи и журнал вызовов Mock API; тесты последовательно сбрасывают состояние.
- Оценивание: 60 баллов функциональность, 25 видео, 10 отчет, 5 читаемость workflow. Видео обязательно.
- Б, Б+, П: качество выполнения одинаковой обязательной работы.
- Э: уровень П + оба дополнения: ограниченный Retry и предотвращение последовательных дубликатов.
- Retry для Э: до 3 попыток всего, промежутки от 0,4 с при 503, без повторов при 400.
- Дубли для Э: второй запрос с существующим `requestId` не создает новую запись, возвращает `already_registered`.
