# Локальный запуск учебного окружения

> Готовый комплект для самостоятельной работы: n8n, Mock API, стартовая заготовка, тестовый раннер и учебные инструкции. Эталонный workflow хранится отдельно у эксперта.

## Требования

- Docker Desktop с работающим Docker Engine и Docker Compose v2 (Windows/macOS) или Docker Engine + плагин Compose (Linux).
- Свободные порты **5678** (n8n) и **8080** (Mock API) на `127.0.0.1`.
- Интернет нужен **один раз** для загрузки образов Docker; после этого учебный пример не обращается к публичным API.
- Регистрация в n8n Cloud, покупка подписки и API-ключи не нужны.

## Запуск

В терминале из корня проекта:

```bash
docker compose up -d
```

Если требуется отслеживать события запуска:

```bash
docker compose ps
docker compose logs -f n8n
```

Откройте **http://localhost:5678**. При первом запуске создайте **локальную** учетную запись владельца (owner). Это не облачная подписка.

Проверка Mock API в браузере: **http://127.0.0.1:8080/users/451**. Ожидается JSON с пользователем Иван Иванов.

## Если n8n уже работал на этапе 2

После обновления файлов (или распаковки нового архива поверх предыдущего) перезапустите сервер Mock API, чтобы Python прочитал измененный исходный код:

```bash
docker compose restart mock-api
```

Содержимое n8n сохраняется в Docker volume и при этом не удаляется. Для проверки всей новой функциональности:

```bash
python tests/smoke_mock_api.py
```

Smoke-тест временно очищает данные Mock API, поэтому выполняйте его отдельно от других экспериментов.

## Импорт учебного workflow

1. Создайте новый workflow в веб-интерфейсе n8n.
2. Откройте меню workflow (три точки) и выберите **Import from File**.
3. Выберите файл `workflows/tutorial-basics.json`.
4. Сохраните workflow и запустите его через **Execute workflow**.
5. Поочередно откройте входные и выходные данные узлов, прочитайте Sticky Notes.
6. Поменяйте `userId` в узле **Example input** с `451` на `452`; повторите запуск. В ответе HTTP Request должна появиться Мария Смирнова, а Switch выберет ветку Finance.

**Важно:** учебный workflow не содержит Webhook приема обращений, регистрацию заявок, обработку ошибок и экспертные дополнения. Он лишь показывает основные узлы и принципы передачи данных. После практикума изучите [ASSIGNMENT.md](ASSIGNMENT.md) и импортируйте `workflows/student-starter.json` как отдельный workflow.

## Адреса внутри и снаружи контейнеров

| Где выполняется запрос | Адрес |
|---|---|
| Браузер компьютера → n8n | `http://localhost:5678` |
| Компьютер → Mock API | `http://127.0.0.1:8080/users/451` |
| Узел HTTP Request внутри n8n → Mock API | `http://mock-api:8080/users/451` |

**`localhost` внутри контейнера n8n указывает на сам контейнер n8n, а не на Mock API.**

## Остановка / повторный запуск

```bash
docker compose down        # Останавливает контейнеры; сохраненные workflow остаются в volume

docker compose up -d       # Повторный запуск
```

Не используйте `docker compose down -v`, если хотите сохранить работу: эта команда удаляет volume с данными n8n.

## Частые проблемы

| Симптом | Возможная причина / решение |
|---|---|
| `docker` не найден | Установите Docker Desktop (или Docker Engine + Compose) и запустите Docker |
| Порт `5678` занят | Закройте конфликтующий сервис или измените маппинг порта в `compose.yaml` и актуализируйте ссылки в инструкциях |
| Страница не открывается | Выполните `docker compose ps` и `docker compose logs n8n` |
| В HTTP Request написано `ECONNREFUSED` | Проверьте `docker compose ps` и адрес `http://mock-api:8080` внутри workflow |
| Запрос в API возвращает 404 | Проверьте путь и ID: пользователи только 451/452/453, несуществующие обращения возвращают `REQUEST_NOT_FOUND` |
| Запрошено создать owner | Обычный первый запуск локального n8n; создайте учетную запись |

## Безопасность

Это **локальная лабораторная конфигурация**, не подходящая для публичного сервера. Порты доступны только с этого компьютера. `N8N_SECURE_COOKIE=false` допустимо здесь лишь потому, что лабораторное окружение использует локальный HTTP. Не открывайте порты наружу и не помещайте реальные секреты в учебный workflow.

Официальные источники: [n8n: установка с Docker Compose](https://docs.n8n.io/deploy/host-n8n/install-options/install-using-docker-compose/), [Импорт и экспорт workflow](https://docs.n8n.io/workflows/export-import/).
